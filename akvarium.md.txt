### Проблемы и предложения по улучшению

#### 🔴 КРИТИЧЕСКИЕ — юзабилити

**1. Нет пустого состояния (Empty State)**
В переводах есть ключи `aquarium.empty_title` и `aquarium.empty_desc`, но в компоненте они **нигде не рендерятся**. Если нет ключей — видишь пустой танк с водорослями и медузами. Пользователь не понимает, что делать.

```tsx
// Нужно добавить после аквариум-танка:
{fishes.length === 0 && (
  <motion.div className="aquarium-empty-state" ...>
    <FishIcon size={48} />
    <h3>{t('aquarium.empty_title')}</h3>
    <p>{t('aquarium.empty_desc')}</p>
    <button onClick={() => eventBus.emit(EVENTS.NAVIGATE, 'providers')}>
      → {t('nav.providers')}
    </button>
  </motion.div>
)}
```

**2. Info-панель перекрывается рыбами на мобильных**
`.aquarium-info-panel` прижат к `bottom: 1rem; right: 1rem` с `min-width: 200px`. На маленьких экранах панель закрывает половину танка, а рыбки плавают под ней. Нет адаптивного поведения.

**3. Клик по рыбе и клик для бросания еды — один и тот же обработчик**
`handleContainerClick` проверяет `e.target !== containerRef.current`, но клик по рыбе (z-index: 10) не достигает контейнера, а вот клик по пузырьку, легенде, подсказке — да, что создаёт еду в неожиданных местах. Нужна более точная проверка цели клика.

**4. Speech-bubble обрезается границами танка**
`.aquarium-speech-bubble` с `max-width: 200px` позиционируется на `y: -40` от рыбы. Если рыба у верхнего края (y < 25%), speech-bubble уходит за границу `overflow: hidden` и не видна. Та же проблема с рыбами у правого/левого края.

#### 🟠 ВЫСОКИЕ — верстка и UX

**5. Footer grid на 3 колонки, но карточки только 2**
`.aquarium-footer { grid-template-columns: 1fr 1fr 1fr }` — CSS заявляет 3 колонки, а рендерится только 2 карточки (ecosystem health + agent population). Третья колонка пустая, карточки растягиваются некрасиво. Либо нужно 2 колонки, либо добавить третью карточку (например, "Total Requests" или "Avg Latency").

**6. Легенда и подсказка внутри танка — мешают взаимодействию**
`.aquarium-legend` и `.aquarium-hint` расположены внутри `.aquarium-tank`, но у них нет `pointer-events: none`. Клик по легенде создаёт еду. Плюс они визуально конфликтуют с рыбами. Лучше вынести их за пределы танка или сделать полупрозрачными с `pointer-events: none`.

**7. Рыбы — просто FishIcon, нет визуальной дифференциации**
Все рыбы используют один и тот же `FishIcon` от lucide-react, отличаясь только цветом и размером. При 5+ провайдерах одинаковые силуэты рыб сливаются. Лично я бы добавил:
- Разные иконки/формы для разных провайдеров (кит для OpenAI, осьминог для Anthropic, дельфин для Gemini и т.д.)
- Или хотя бы разные SVG-формы рыб с учётом personality

**8. Нет pause/resume для анимации**
Анимация бежит бесконечно через `setInterval(250ms)`. Нет кнопки паузы. На слабых устройствах это жрёт CPU/GPU. Нужна кнопка паузы + `requestAnimationFrame` вместо `setInterval` для плавности.

**9. Provider color mapping — hardcoded, не синхронизирован с другими панелями**
`providerColors` захардкожен внутри компонента. Если в HealthPanel или ProvidersPanel другие цвета — визуальная несогласованность. Нужен единый источник цветов провайдеров.

**10. Энергобар рыб не интуитивен**
Энергобар (`.aquarium-energy-bar-bg/fill`) показывается всегда, но что он означает — непонятно. Энергия падает на 0.05 каждый тик, растёт при поедании. Нет tooltip, нет числового значения, нет объяснения «почему рыба устала». Пользователь не понимает, что с этим делать.

#### 🟡 СРЕДНИЕ — код и полировка

**11. 658 строк в одном компоненте — монолит**
Все интерфейсы, логика движения, обработка событий, рендер рыб/медуз/водорослей/еды/пузырьков/бота/ripples — всё в одном файле. Стоит вынести:
- `useAquariumEngine` — хук с логикой движения и событий
- `useAquariumScene` — декоративные элементы (медузы, водоросли, бот)
- Подкомпоненты: `<Fish>`, `<Jellyfish>`, `<Seaweed>`, `<FoodParticle>`, `<Bubble>`, `<CleanerBot>`

**12. Bubble leak — data-пузырьки накапливаются**
```tsx
setBubbles(prevB => [...prevB, ...dataBubbles]);
```
При активном чате data-пузырьки добавляются при каждом ответе. Очистка происходит через 5 секунд, но фильтр `prevB.filter(b => b.type !== 'data')` удаляет ВСЕ data-пузырьки разом, даже те, которые только что появились. Нужно трекать по ID, а не по типу.

**13. Рефы на state — антипаттерн**
```tsx
useEffect(() => { foodRef.current = food; }, [food]);
useEffect(() => { keysRef.current = keys; }, [keys]);
useEffect(() => { mousePosRef.current = mousePos; }, [mousePos]);
```
Три отдельных эффекта для синхронизации рефов. Можно заменить на один `useEffect` или использовать `useLatest` из хуков.

**14. Deprecated но работает — противоречие**
Строка 1: `DEPRECATED — pure visual animation, same data as HealthPanel. Will be removed in a future version.` Но это явно любимая фича! Может стоит убрать DEPRECATED и признать полноценным модулем? Или чётко описать путь миграции.

**15. Нет клавиатурной навигации по рыбам**
Рыбы имеют `tabIndex={0}` и `onKeyDown`, но нет стрелочной навигации между ними. Tab-index не управляется, при 10+ рыбах клавиатурный доступ становится хаотичным.

**16. Тесты не покрывают интерактивность**
Тесты проверяют только рендер статического контента. Нет тестов на: кормление рыб, клик по рыбе (открытие info-панели), движение курсора, обработку MESSAGE_RESPONSE события.

#### 🟢 МЕЛКИЕ — полировка

**17. LATENCY/SUCCESS в info-панели — не локализованы**
Строки 593-596: `LATENCY` и `SUCCESS` — захардкожены на английском, хотя остальные тексты локализованы.

**18. Кнопка закрытия info-панели — инлайн-стили вместо класса**
Строка 576: кнопка ✕ с огромным инлайн-стилем. Нужно вынести в CSS-класс для консистентности.

**19. Название провайдера в легенде — lowercase**
`providerColors` маппит lowercase ключи (`openrouter`, `gemini`), и в легенде они отображаются так же. Выглядит не очень — "openrouter" вместо "OpenRouter".

**20. Водоросли могут перекрывать друг друга**
`seaweeds` создаются с `left: i * 7`, что даёт 15 водорослей на 105% ширины. При ширине 10-30px они перекрываются, что выглядит неестественно.
