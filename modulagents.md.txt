1. **Нет жизненного цикла агента** — агент либо `active`, либо `paused` (через `disabledNodes`). Нет состояний `initializing`, `busy`, `idle`, `error`, `terminated`

### AW-01: Agent Lifecycle State Machine

Сейчас: `active | paused` (через `disabledNodes: Set<string>`)

Надо:

```typescript
// src/kernel/contracts/topology.ts — расширить
export type AgentLifecycleState = 
  | 'initializing'  // агент создан, конфигурируется
  | 'ready'         // готов принимать запросы
  | 'busy'          // выполняет запрос
  | 'idle'          // завершён, ждёт следующий
  | 'paused'        // явно остановлен пользователем

  | 'terminated';   // удалён, но данные ещё в истории

// В ISNode.config добавить:
interface AgentConfig {

  lifecycle?: {
    state: AgentLifecycleState;
    since: number;          // timestamp перехода
    transitions: Array<{ from: AgentLifecycleState; to: AgentLifecycleState; at: number; reason?: string }>;
  };
}
```

**Где менять**:
- `OrchestrationService.processNode()` — перед выполнением: `ready → busy`, после: `busy → idle`
- `AgentService.spawnAgent()` — создавать в `initializing`, после mount: `initializing → ready`
- `AgentService.toggleAgent()` — `ready/idle → paused`, `paused → ready`
- Новое событие `AGENT_LIFECYCLE_CHANGE` в event-names.ts

## ФАЗА 2: Concurrent Execution & Scheduling (Performance)

### AW-05: Parallel Branch Execution

Сейчас: `OrchestrationService.processNode()` (строка 206) обходит `nextEdges` через `for...of` — **последовательно**.

```typescript
// Сейчас:
for (const edge of nextEdges) {
  const nextNode = this.activeTopology?.nodes.find(n => n.id === edge.to);
  if (nextNode) await this.processNode(nextNode, nextData, mode, new Set(visited));
}
```

Надо:

```typescript
// Параллельное выполнение sibling-веток с concurrency limit
const PARALLEL_LIMIT = 3; // настраиваемый

const parallelEdges = nextEdges.filter(e => e.trigger === 'on_success' || e.trigger === 'data_flow');
const errorEdges = nextEdges.filter(e => e.trigger === 'on_error');

if (status === 'error' && errorEdges.length > 0) {
  // Error path — последовательный
  for (const edge of errorEdges) { ... }
} else if (parallelEdges.length > 1) {
  // Параллельный запуск с ограничением
  await this.executeParallel(parallelEdges, nextData, mode, visited, PARALLEL_LIMIT);
} else {
  // Одиночный путь — как раньше
  ...
}
```

```typescript
private async executeParallel(
  edges: ISEdge[], data: NodeContext, mode: string, 
  visited: Set<string>, concurrency: number
): Promise<void> {
  const chunks: ISEdge[][] = [];
  for (let i = 0; i < edges.length; i += concurrency) {
    chunks.push(edges.slice(i, i + concurrency));
  }
  for (const chunk of chunks) {
    await Promise.allSettled(
      chunk.map(edge => {
        const node = this.activeTopology?.nodes.find(n => n.id === edge.to);
        return node ? this.processNode(node, data, mode, new Set(visited)) : Promise.resolve();
      })
    );
  }
}
```
