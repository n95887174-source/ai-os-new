SUPERAGENTS OS — COMPREHENSIVE AI CONTEXT v3.4.0
==============================================

PROJECT IDENTITY:
-----------------
SuperAgents OS is an observable, event-driven, decision-centric multi-agent intelligence operating system.
It transforms LLM interactions from a chat-based paradigm to a programmable cognitive infrastructure.

CORE ARCHITECTURE:
------------------
1. KERNEL: Central lifecycle manager for services and event loops.
2. EVENT BUS: Asynchronous communication backbone using strict event schemas.
3. INTELLIGENCE DSL: JSON-based specification for defining cognitive topologies (nodes & edges).
4. ORCHESTRATOR: The engine that parses DSL and executes multi-agent workflows.

DECISION-CENTRIC MODEL (DCM):
-----------------------------
The atomic unit of intelligence is the 'Decision'.
Schema: goal, input, alternatives (with scores/reasoning), constraints, selectedId, logic, confidence, causalChain.

COGNITIVE LAYERS:
-----------------
- Layer 1: Execution (Agents & Tools)
- Layer 2: Coordination (Orchestrator & DSL)
- Layer 3: Reasoning (Debates & Dialectics)
- Layer 4: Observability (Traces, Events, Replay)
- Layer 5: Interpretation (Advisor, Knowledge Graph, Simulation)

KEY COMPONENTS & SERVICES:
--------------------------
- CognitiveBuilder: Visual drag-and-drop workspace for Intelligence DSL.
- MissionControl: Unified "War Room" for autonomous oversight.
- TracesPanel: Cognitive debugger with "Cognition Replay" functionality.
- MemoryMesh: Persistent semantic storage for long-term fragments.
- DebateService: Round-based multi-agent argumentation and consensus.
- PolicyService: Global guardrails for Latency, Privacy, and Cost.
- AdvisorService: Meta-agent for autonomous self-optimization.
- SnapshotService: State-aware replay system.

VISUAL PARADIGMS:
-----------------
- Aquarium: Behavioral observation view.
- Radar: High-level system health and status.
- Microscope: Deep interpretability of individual decisions.
- Explorer: Semantic knowledge graph navigation.

TECHNOLOGY STACK:
-----------------
- React, TypeScript, Framer Motion, Lucide, Vite.
- Node.js, EventBus, SQLite (simulated), Vector Index (simulated).

DEVELOPMENT STATUS:
-------------------

- Observability: High-Fidelity.
- Builder: Operational.
- Autonomous Ecosystem: Phase 7 Experimental (Live).

FUTURE ROADMAP:
---------------

- Self-healing cognitive topologies based on simulation outcomes.
- Deep integration with local model runtimes for zero-latency execution.
