SUPERAGENTS OS — COMPREHENSIVE AI CONTEXT v3.7.0
==============================================

PROJECT IDENTITY:
-----------------
SuperAgents OS is an observable, event-driven, decision-centric multi-agent intelligence operating system.
It transforms LLM interactions from a chat-based paradigm to a programmable cognitive infrastructure.

CORE ARCHITECTURE:
------------------
1. EVENT BUS: Asynchronous communication backbone using strict event schemas (src/core/events.ts).
2. MEMORY SERVICE: Hybrid search — Orama BM25 (Web Worker) + Transformers.js embeddings (Web Worker) + Dexie persistence.
3. ORCHESTRATOR: Event-driven execution engine for multi-agent workflows.
4. SERVICE LAYER: 8+ singletons (Agent, Chat, Cognitive, Policy, Tool, MCP, Health, Sandbox, etc.).

SEARCH & MEMORY:
----------------
- Orama (full-text BM25) runs in a dedicated Web Worker (memory.worker.ts) — no main-thread blocking.
- Transformers.js (all-MiniLM-L6-v2, 384-dim) generates embeddings in the same worker on store.
- Semantic search: query embedding + cosine similarity against all cached vectors.
- Three search modes: semantic, fulltext, auto (tries semantic fallbacks to fulltext).
- Vectors persisted in Dexie (IndexedDB) alongside MemoryEntry.

PERSISTENCE (Dexie/IndexedDB):
------------------------------
- Tables: notes, memories, apiKeys, sessions, traces, roles, cognitiveTraces, skills, connectors.
- Schema versioning (v5) with incremental migrations.

TECHNOLOGY STACK:
-----------------
- React 19, TypeScript 6, Framer Motion, Lucide, Vite 8.
- Dexie 4 (IndexedDB), Orama 3 (full-text), @huggingface/transformers 4 (embeddings).
- Vitest for testing (14 tests).
- Web Workers: sandbox.worker (code isolation) + memory.worker (search + embeddings).

DEVELOPMENT STATUS:
-------------------
- Core Runtime: Stable.
- Search Infrastructure: Stable (Worker offload + real embeddings).
- Panels (Roles, Tasks, Skills, Connectors, Agents): All migrated to Dexie.
- Documentation: Accurate and up-to-date.
