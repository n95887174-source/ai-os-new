# SuperAgents OS v3.7.0 — Встроенный поиск и Web Worker Runtime

### 🧠 Ядро и Архитектура
- **EventBus**: Типизированная шина событий (`src/core/events.ts`)
- **Kernel**: Единственный источник истины, редуктор состояния
- **Dexie.js (IndexedDB)**: Persistent storage для памяти, ключей, сессий, трейсов, ролей, навыков, коннекторов
- **Web Workers**: memory.worker (Orama BM25 + Transformers.js эмбеддинги), sandbox.worker (изоляция JS)

### 🔍 Поиск (Web Worker)
- **Orama BM25**: Полнотекстовый поиск в отдельном потоке
- **Transformers.js (all-MiniLM-L6-v2, 384-dim)**: Реальный семантический поиск
- **Три режима**: semantic, fulltext, auto (semantic → Orama → substring)
- **Синхронизация векторов**: Асинхронный backfill в Dexie

### 📦 UI и Компоненты
- 7 панелей с компонентными тестами: Analytics, Chat, Dashboard, Events, Health, Memory, Traces
- Все панели обёрнуты в ErrorBoundary
- Design: тёмный glassmorphism, Framer Motion, Lucide

### 🛠 Стек Технологий
- React 19.2.5, Vite 8.0.10, TypeScript 6.0.3
- Vitest — 32 тестовых файла, 192 теста проходят
- Dexie.js 4, Orama 3, @huggingface/transformers 4

### ✅ Ключевые возможности
- Decision-Centric Model (каждое действие — CognitiveDecision)
- Intelligence DSL (DAG-топологии)
- Blackboard координация агентов
- MCP поддержка
- Безопасный Sandbox (Capability API)
- Единый стриминг через прокси (без CORS)
- Auto-429 детекция, circuit breaker
- Provider Sandbox (мини-чат для каждого ключа)
