# SuperAgents OS v3.7.1 — Component Testing & Worker Runtime

## 1. Project Overview
SuperAgents OS — event-driven, decision-centric multi-agent intelligence operating system. Transforms LLM interactions from chat paradigm to programmable cognitive infrastructure.

## 2. Core Architecture

### Kernel (`src/core/Kernel.ts`)
Single Source of Truth. Contains system state, provider metrics, routing weights, decision history. State changes only through reducer, emits `kernel:updated` event after each change.

### EventBus (`src/core/events.ts`)
Central typed communication bus. All services and components communicate exclusively through events, fully decoupling UI from business logic.

### Persistence
- **Dexie.js (IndexedDB)**: Primary storage for memories, API keys, sessions, traces, roles, skills, connectors.
- **Web Workers**: memory.worker (Orama BM25 + Transformers.js embeddings), sandbox.worker (isolated JS execution).

## 4. Search & Memory
- **Orama BM25**: Full-text search in dedicated Web Worker (memory.worker.ts)
- **Transformers.js**: all-MiniLM-L6-v2 (384-dim) for real semantic search, same worker
- **Hybrid modes**: semantic (cosine similarity), fulltext (BM25), auto (semantic → fulltext → substring)
- **Vector persistence**: Embeddings stored in Dexie, backfilled async via `backfillVector()`

## 5. UI Panels
- 7 component-tested panels: AnalyticsPanel, ChatPanel, DashboardPanel, EventsPanel, HealthPanel, MemoryPanel, TracesPanel (7/21 coverage)
- All panels wrapped with ErrorBoundary (single panel crash never brings down the app)

## 6. Technology Stack
- **Frontend**: React 19.2.5, Vite 8.0.10, TypeScript 6.0.3
- **Design**: Custom dark glassmorphism, Framer Motion, Lucide React
- **Database**: Dexie.js 4 (IndexedDB)
- **Search**: Orama 3 (full-text), @huggingface/transformers 4 (embeddings)
- **Testing**: Vitest — 32 test files, 192 tests passing

## 7. Key Features
- **Event-Driven Core**: All actions are events (observable, reactive)
- **Decision-Centric Model**: Every AI action wrapped in CognitiveDecision
- **Intelligence DSL**: JSON-based formal language for cognitive topologies
- **Visual Builder**: Drag-and-drop DAG topology editor (React Flow)
- **MCP Support**: Model Context Protocol for external data
- **Secure Sandbox**: WebWorker isolation via Capability API
- **Streaming**: Unified streaming across all provider adapters
- **Error Recovery**: Auto-429 detection, zero-crash metrics, circuit breaker
