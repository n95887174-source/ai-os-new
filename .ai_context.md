## 🧠 Core Architecture (v4.1.0 — Kernel Consolidation)

### Dependency Rule Enforced
- **`src/kernel/`** is the single source of truth — all business logic lives here
- **`src/services/`** are thin Proxy wrappers (≤15 lines, no business logic)
- **`src/types/`** re-exports from `src/kernel/types/`
- **Zero kernel imports** from `src/services/`, `src/types/`, `src/core/`, or `src/utils/`

### Transaction Boundary (v4.1.0)
- `kernel.transaction(fn)` wraps mutations atomically: deferred persistence → deferred event emission → commit hooks
- Rollback drops all queues. Contract: `ITransaction` / `ITransactional`
- All mutation methods accept optional `tx?: ITransaction`

### Lifecycle Standard (v4.1.0)
- `ILifecycle` contract: `init() → start() → destroy()` for every kernel service
- `LifecycleManager`: register → initAll → startAll → shutdown (LIFO). Dedup by name
- Constructor rule: never async, no side effects, no `this.load()` / `this.setupListeners()`

### Observability (v4.2.0)
- `ILogger` contract: `debug/info/warn/error` with structured `LogEntry`
- `LoggerService`: buffers last 500 entries, queryable by service/level/traceId
- `TraceContext`: `enter()`/`exit()` stack for span propagation
- `EventBus` accepts optional `ILogger`

### Key Services
- **`src/kernel/services/key-management/`**: KeyVault, KeyRegistry, health, quotas, analytics, fingerprints, alerts, lifecycle
- **`src/kernel/services/rotation-service.ts`**: Full key rotation engine (migrated from legacy)
- **`src/kernel/services/provider-runtime/`**: Instances, sessions, state, budget
- **`src/kernel/services/event-sourcing/`**: Recorder, checkpoints, replay engine
- **`src/kernel/services/advisor/`**: Advisor logic

### Contract Interfaces
- **32** contract interfaces in `src/kernel/contracts/` (IKeyVault, IProviderAdapter, IBudgetService, ILifecycle, ILogger, ITransaction, IRotationService, etc.)

### Types & Schemas
- **16 Zod schemas** + `EventValidators` in `src/kernel/types/schema-types.ts`
- Legacy `src/types/*.ts` files now re-export from kernel

### KeyRegistry Fix
- No longer seeds 6 placeholder keys with empty `key: ''` on construction
- Filters out legacy demo entries from IndexedDB on load

## 📡 EventBus Cheat Sheet (V3 Core)

| Event | Payload | Description |
|-------|---------|-------------|
| `cognitive:step:active` | `{nodeId, traceId, metadata?}` | Orchestrator starts processing a DSL node. |
| `cognitive:step:completed` | `{nodeId, traceId, decision, output, duration}` | Node execution finished. Triggers tracers. |
| `system:topology:mounted` | `any` | A new intelligence graph is loaded. |
| `advisor:suggestion` | `any` | Meta-agent proposes structural changes. |
| `memory:updated` | `any[]` | MemoryMesh updated (new cognitive fragment with optional embedding vector). |
| `policy:violation` | `any` | Guardrail alert (Latency, Privacy, Cost). |
| `debate:argument` | `any` | New perspective added to the Dialectic Arena. |

## ⚠️ Critical Rules for AI Agents

### 1. TypeScript Strictness
- **`verbatimModuleSyntax`** is enabled. Use `import type` for all type-only imports.
- Never mix types and values in a single `import` statement.

### 2. Decision Wrapping
- When implementing new agentic logic, ensure the output is captured as a `Decision` with alternative reasoning.
- Use `CognitiveService.recordDecision()` to ensure visibility in the Debugger.

### 3. DSL Compliance
- All multi-agent workflows MUST be defined as an `ISTopology`.
- The Orchestrator is the only service that should manage the execution flow between nodes.

### 4. Observability First
- Emit `cognitive:step` events for every logical stage of reasoning.
- This ensures the **Cognition Replay** and **Decision Graph** function correctly.

### 5. IS-Policies
- Always check `PolicyService.getPolicies()` before performing high-cost or high-latency operations.
- Honor PII redaction rules if the `privacy` policy is active.
