# AI Agent Context — SuperAgents OS v3.4.0
> **The Observable and Programmable Intelligence Operating System**

This project is an **autonomous, event-driven, decision-centric multi-agent runtime**. It shifts the focus from simple LLM chat to structured cognitive execution.

---

## 🧠 Core Architecture (Phase 7)

### Single Source of Truth
- **`src/core/IntelligenceDSL.ts`**: Formal specification for cognitive topologies.
- **`src/services/OrchestrationService.ts`**: The execution engine that mounts and runs DSL topologies.
- **`src/core/events.ts`**: The global `EventBus` singleton for all inter-service communication.

### Decision-Centric Model (DCM)
- The atom of intelligence is the **Decision** (`src/services/CognitiveService.ts`).
- Every meaningful AI action MUST be wrapped in a `CognitiveDecision` object containing: goals, alternatives, reasoning, and confidence.

### Cognitive Layers
1. **Execution:** `src/services/AgentService.ts`, `src/services/ToolService.ts`.
2. **Coordination:** `src/services/OrchestrationService.ts`.
3. **Reasoning:** `src/services/DebateService.ts`.
4. **Observability:** `src/services/TraceService.ts`, `src/services/SnapshotService.ts`.
5. **Interpretation:** `src/services/AdvisorService.ts`, `src/services/MemoryService.ts`.

## 📡 EventBus Cheat Sheet (V3 Core)

| Event | Payload | Description |
|-------|---------|-------------|
| `cognitive:step:active` | `{nodeId, status}` | Orchestrator starts processing a DSL node. |
| `cognitive:step:completed` | `{nodeId, decision, output}` | Node execution finished. Triggers tracers. |
| `system:topology:mounted` | `ISTopology` | A new intelligence graph is loaded. |
| `advisor:suggestion` | `OptimizationSuggestion` | Meta-agent proposes structural changes. |
| `memory:updated` | `MemoryEntry[]` | MemoryMesh updated with new cognitive fragments. |
| `policy:violation` | `PolicyViolation` | Guardrail alert (Latency, Privacy, Cost). |
| `debate:argument` | `DebateArgument` | New perspective added to the Dialectic Arena. |

## ⚠️ Critical Rules for AI Agents

### 1. TypeScript Strictness
- **`verbatimModuleSyntax`** is enabled. Use `import type` for all type-only imports.
- Never mix types and values in a single `import` statement.

### 2. Decision Wrapping
- When implementing new agentic logic, ensure the output is captured as a `Decision` with alternative reasoning.
- Use `CognitiveService.recordDecision()` to ensure visibility in the Debugger.

### 3. DSL Compliance
- All multi-agent workflows MUST be defined as an `ISTopology`.
- The Orchestrator is the only service that should manage the execution flow between nodes.

### 4. Observability First
- Emit `cognitive:step` events for every logical stage of reasoning.
- This ensures the **Cognition Replay** and **Decision Graph** function correctly.

### 5. IS-Policies
- Always check `PolicyService.getPolicies()` before performing high-cost or high-latency operations.
- Honor PII redaction rules if the `privacy` policy is active.
