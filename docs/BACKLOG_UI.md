## Высокий приоритет (5 шт) — новая панель

### H-01: BudgetPanel — контроль бюджета

**Сервис:** BudgetService (153 строки), CostManagerDecorator (167 строк)
**Сейчас:** Цены видны в PricingPanel, но нет UI для лимитов, алертов, истории расходов
**Панель:**
- Дневной/недельный/месячный лимит по провайдеру
- Прогресс-бар «потрачено / осталось»
- История списаний по дням
- Алерт при превышении порога
- Кнопка «остановить всё при превышении»
**Сложность:** Средняя (2-3 ч)
**Эффект:** Пользователь видит деньги, а не только графики

---

### H-02: RotationsPanel — управление ротацией ключей

**Сервис:** RotationService (263 строки)
**Сейчас:** Ключи ротируются автоматически, пользователь не видит когда и как
**Панель:**
- Список ключей с датой последней ротации
- Счётчик «ротация через N дней»
- История ротаций (когда был создан новый ключ, когда удалён старый)
- Кнопка «ротировать сейчас»
**Сложность:** Средняя (2 ч)
**Эффект:** Прозрачность безопасности ключей

---

### H-03: CachePanel/StoragePanel — состояние кэша

**Сервис:** CacheService (116 строк), CacheDecorator (152 строки)
**Сейчас:** Кэш работает прозрачно — пользователь не знает, кэшируется ли ответ или нет
**Панель:**
- Статистика: hit/miss ratio, размер кэша, количество записей
- Просмотр закэшированных запросов (truncated)
- Кнопка «очистить кэш»
- ТTL таймеры
**Сложность:** Малая (1 ч)
**Эффект:** Прозрачность, отладка

## Никогда (4 шт) — внутренняя инфраструктура

Эти сервисы никогда не должны иметь UI — они архитектурно внутренние:

| Сервис | Причина |
|--------|---------|
| **ProviderAdapterRegistry** | Абстракция над AdapterFactory — нечего показывать |
| **LifecycleManager** | init/start/destroy — запускается при старте |
| **KeyVaultService** | Шифрование прозрачно — нечего показывать |
| **VirtualKeyService** | Используется ChatService, не для пользователя |
