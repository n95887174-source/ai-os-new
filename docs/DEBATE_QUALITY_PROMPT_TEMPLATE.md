# Промпт для сбора идей по улучшению дебатов

Скопируй этот текст и отправь разным AI (ChatGPT, Claude, Gemini, Grok и т.д.).

---

## Контекст (отправляй как есть)

```
У нас есть мульти-агентная система дебатов на TypeScript. Текущая архитектура:

**Уже реализовано:**
- Round-robin с 20+ агентами, у каждого своя роль/личность (50+ персонажей)
- Structured prompting: тезис + обоснование + доказательство (аналог CREP)
- DebateEvaluator с 6 критериями: argumentQuality, rebuttalStrength, coherence, persuasiveness, factuality, overall
- ResearchEngine с 34 API (ArXiv, PubMed, Semantic Scholar, Wikipedia, Google Custom Search и др.)
- RAGRetriever для инжекции фактов в промпт агента
- MemoryExtractor: вычленение claims из аргументов, хранение в графе
- SleepEngine: фоновая консолидация памяти каждые N мутаций
- 7 видов памяти: working, episodic, semantic, procedural, emotional, social, spatial
- Температура: глобальный slider 0-10 + per-agent конфиг
- Поддержка Citation Graph между аргументами
- Consensus Engine с scoring и вердиктом
- DebateInterpreter: анализ disagreement peak, trajectory changers, insights

**Чего пока нет (дыры):**
- Cross-examination: агент цитирует оппонента, разбивает point-by-point, потом даёт свой аргумент
- Pre-publish Critic: черновик → LLM-ревью → финальная версия перед отправкой
- Динамический подбор персонажа под тему дебатов
- Фактчекинг утверждений ОППОНЕНТА в реальном времени (сейчас RAG только для своих)
- Совещание судей: независимые оценки → раунд обсуждения → консенсус
- Strategist: анализ прошедших раундов, адаптация линии аргументации
- Best-of-N: генерация N вариантов, отбор лучшего
- Lincoln-Douglas с перекрёстным допросом вместо round-robin
- Оценка rebuttal: насколько хорошо агент уничтожил аргумент оппонента

Тема дебатов — произвольная (пользователь выбирает).
Модели — Groq (llama), Gemini, NVIDIA, OpenRouter (любые OpenAI-совместимые).
Язык — русский, но промпты билингвальные.

## Твоя задача

Предложи 3-5 конкретных, нетривиальных техник/паттернов/механик, которые УЛУЧШАТ КАЧЕСТВО ДЕБАТОВ. Не повторяй то, что уже есть в списке "реализовано" или "дыры".

Для каждой техники напиши:
1. Название
2. Какую конкретно проблему решает
3. Как технически внедрить (какие модули менять)
4. Оценка сложности (1-5) и приоритет (P0/P1/P2)
5. Ожидаемый эффект: на сколько процентов улучшится качество и по какой метрике

Фокус на:
- Убедительность аргументов
- Глубину столкновения позиций
- Честность вердикта
- Естественность и человечность диалога
- Разнообразие стратегий между разными агентами
```

## Как собирать результаты

После получения ответа от каждого AI:

1. Сохраняй ответ в `docs/ai-ideas/{ai-name}.md`
2. Записывай только то, чего нет в текущем `DEBATE_QUALITY_IMPROVEMENTS.md`
3. Если идея глубже/конкретнее существующего пункта — дополни его
