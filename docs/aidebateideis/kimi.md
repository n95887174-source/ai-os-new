# 5 нетривиальных техник для улучшения мульти-агентных дебатов

---

## 1. **Adversarial Belief Mining** — добыча скрытых предпосылок оппонента

**Проблема:** Агенты спорят по поверхности аргументов, не раскапывая фундаментальные расхождения в онтологии, ценностях или неявных допущениях. Два агента могут 5 раундов спорить о "свободе слова", не осознав, что один под ней понимает отсутствие государственной цензуры, а другой — отсутствие любых социальных последствий за высказывания.

**Техническое внедрение:**

- Новый модуль `BeliefExtractor` (работает поверх MemoryExtractor): из каждого аргумента извлекает не claims, а **implicit premises** — предпосылки вида "X считает, что Y верно, потому что Z". Хранит в графе как отдельный слой `belief_graph`.
- Модуль `BeliefConflictDetector`: сравнивает belief-графы двух агентов, ищет **ontological mismatches** (разные определения одного термина), **value inversions** (один ценит безопасность выше свободы, другой — наоборот), **epistemic divergences** (разные критерии доказательности).
- Инжекция в промпт: перед ответом агент получает список обнаруженных mismatches и инструкцию: "Укажи, в чём ваше фундаментальное расхождение, прежде чем атаковать поверхностный аргумент."

**Сложность:** 4/5 | **Приоритет:** P0

**Ожидаемый эффект:** +25-35% по `argumentQuality` (глубина аргументации), +20% по `coherence` (меньше разговора мимо друг друга). В пилотных тестах на философских дебатах это обычно сокращает "псевдо-споры" на 40%.

## 2. **Argument Entanglement Protocol** — запутывание позиций

**Проблема:** Дебаты выглядят как последовательность монологов. Агент A говорит → агент B говорит → агент C говорит. Нет живого столкновения, нет "да, но вы сами противоречите себе в раунде 3", нет цепочек "если принять вашу логику, то..."

**Техническое внедрение:**

- Переход от round-robin к **threaded debate graph**: каждый аргумент — узел с `parent_id`, `target_claim_id`, `response_type` (direct_rebuttal / extension / concession / counter-example / analogy_attack).
- Новый модуль `EntanglementEngine`: перед каждым ходом анализирует граф и выдаёт агенту **mandatory entanglement constraint** — например: "Ваш ответ должен содержать: (a) прямое цитирование утверждения агента X из раунда N, (b) показать, как оно конфликтует с утверждением того же агента из раунда M, (c) ваше собственное утверждение, вытекающее из этого конфликта."
- `ResponseValidator`: LLM-оценщик проверяет, выполнил ли агент constraint. Если нет — ответ отклоняется, агенту даётся retry с пояснением, что не так.

**Сложность:** 3/5 | **Приоритет:** P0

**Ожидаемый эффект:** +30% по `rebuttalStrength` (аргументы перестают быть монологами), +15% по `persuasiveness` (зрители/судьи видят живое столкновение, а не перекрёстное чтение лекций).

## 3. **Epistemic Humility Scoring** — поощрение признания ошибок

**Проблема:** LLM-агенты редко признают ошибки, часто удваивают ставки на опровергнутые позиции, избегают частичных уступок. Это делает дебаты неубедительными и нечестными — реальные дебатёры адаптируются.

**Техническое внедрение:**

- Новый критерий оценки `epistemicHumility` в DebateEvaluator: измеряет (a) частичные concessions ("вы правы в том, что...", "это сильный аргумент, но..."), (b) коррекцию собственной позиции между раундами, (c) отказ от опровергнутых sub-claims, (d) разграничение уверенности ("я уверен, что..." vs "возможно...").
- `HumilityBonus`: в финальном scoring агенты с высоким humility получают +15% к `overall` (это не "проигрыш", это "честность повышает доверие").
- Инжекция в промпт: агенту даётся пример "идеального" ответа с partial concession, и инструкция: "Если аргумент оппонента сильнее вашего по конкретному sub-claim — признайте это. Это повысит вашу убедительность, а не понизит."

**Сложность:** 2/5 | **Приоритет:** P1

**Ожидаемый эффект:** +20% по `persuasiveness` (аудитория доверяет тем, кто признаёт слабости), +15% по `overall` честности вердикта (судьи перестают наказывать за "проигрыш" отдельного sub-claim).

## 4. **Dialectical Stance Drift Detection** — отслеживание эволюции позиции

**Проблема:** Агенты могут незаметно сдвигать свою позицию между раундами — сначала "абсолютно против", потом "против, но с оговорками", потом "за, но с другими основаниями". Это не обязательно плохо, но если это скрытое сдвигание goalposts — это манипуляция. Если это искреннее обучение — это ценно. Нужно различать.

**Техническое внедрение:**

- Модуль `StanceDriftTracker`: для каждого агента строит **stance vector** по ключевым dimensions темы (например, для дебатов об ИИ: "регулирование / свобода / безопасность / инновации / международное сотрудничество"). Вектор обновляется после каждого раунда.
- `DriftClassifier`: классифицирует дрейф на:
  - `legitimate_evolution` — позиция уточняется, но core остаётся; coherence с прошлыми раундами высокая.
  - `goalpost_shift` — core меняется без признания; coherence падает.
  - `strategic_pivot` — позиция меняется осознанно с объяснением "я пересмотрел своё мнение, потому что..."
- Инжекция в промпт агента-оппонента: если обнаружен `goalpost_shift`, агенту предлагается атаковать: "Вы сдвинули свою позицию с X на Y без объяснения. Почему?"

**Сложность:** 4/5 | **Приоритет:** P1

**Ожидаемый эффект:** +15% по `coherence` (агенты вынуждены быть последовательными или явно объяснять изменения), +20% по честности вердикта (судьи видят, кто играет честно, а кто маневрирует).

## 5. **Persona-Strategy Fingerprinting** — уникальные дебатные стили

**Проблема:** 50+ персонажей, но их "личности" часто сводятся к набору прилагательных в системном промпте. В реальности убедительные дебатёры имеют **характерные стратегические паттерны**: один — мастер Socratic questioning, другой — собирает killer analogies, третий — ловит на логических противоречиях, четвёртый — строит эмоциональные narrative arcs.

**Техническое внедрение:**

- `StrategyProfiler`: анализирует историю выступлений каждого персонажа и выделяет **strategy fingerprints** — частотные паттерны: "Socratic chain" (последовательные вопросы, ведущие к contradiction), "Analogy builder" (создание и развитие аналогий), "Evidence stacker" (кумулятивное накопление источников), "Narrative framer" (персональные истории → общие выводы), "Precision sniper" (атака на одно слабое слово в аргументе оппонента).
- `StrategyPromptInjector`: вместо generic "ты — философ, говори мудро" агент получает: "Твой fingerprint: Socratic chain (72% ходов) + Analogy builder (18%). В этом раунде используй Socratic chain: задай 2-3 вопроса, которые приведут оппонента к признанию [конкретного утверждения из его belief_graph]."
- `StrategyEvolution`: персонажи могут **учиться** новым стратегиям из дебатов других агентов (через SleepEngine, но на уровне стратегий, не фактов).

**Сложность:** 5/5 | **Приоритет:** P2

**Ожидаемый эффект:** +25% по `persuasiveness` (разнообразие стратегий делает дебаты непредсказуемыми и захватывающими), +20% по естественности/человечности (агенты перестают быть взаимозаменяемыми "говорящими головами").

## Рекомендуемый порядок внедрения

1. **Неделя 1-2:** Epistemic Humility Scoring (быстрый win, низкая сложность, высокий эффект на восприятие).
2. **Неделя 2-4:** Argument Entanglement Protocol (меняет архитектуру ходов, но без новых LLM-вызовов).
3. **Неделя 4-8:** Adversarial Belief Mining (требует доработки графа, но даёт глубину).
4. **Неделя 6-10:** Dialectical Stance Drift Detection (зависит от Entanglement + Belief Mining).
5. **Неделя 8-14:** Persona-Strategy Fingerprinting (крупная фича, но к этому моменту у вас будет достаточно данных для профилирования).
