# SuperAgents OS — Обзор всех разделов меню

## MAIN (Главное)

**Overview** — Дашборд системы: статус провайдеров, количество активных ключей, последние события, график нагрузки. Стартовая точка при входе.

**Chat** — Чат с AI-агентами. Выбор модели, провайдера, темпиратуры. История сообщений сохраняется, можно искать и экспортировать.

**Tasks** — Список активных и завершённых задач. Агенты выполняют их асинхронно, результат приходит в чат.

**SRE Agent** — Специализированный агент для диагностики системы. Анализирует логи, метрики, предлагает исправления.

---

## DEBATES (Дебаты)

**Builder** — Конструктор топологий: создаёшь схему debate-сессии (какие агенты участвуют, в каком порядке выступают, кто судья).

**Debate Arena** — Главная арена: выбираешь тему, до 20 агентов, стратегию (круговая, сократическая, аргумент-дерево). Агенты спорят автоматически.

**Debate Rooms** — Рабочие комнаты: можно следить за несколькими дебатами одновременно, видеть live-результаты.

**Debate Replay** — Повторы завершённых дебатов: пошаговый просмотр, пауза, перемотка.

**Tournament** — Турнирная сетка: несколько пар дебатов, победители проходят дальше.

**Argument Graph** — Граф аргументов: визуализация кто на чьи аргументы отвечал, дерево дискуссии.

**Debate Analysis** — Аналитика: метрики глубины, оригинальности, активности участников, compliance, качество аргументов.

---

## AGENTS (Агенты)

**Live Workspace** — Реальная панель управления агентами. Видно кто сейчас думает, кто ответил, статус каждого.

**Mission Control** — Контроль миссий: постановка целей группе агентов, мониторинг прогресса.

**Agents** — Список всех агентов, их роли, системные промпты. Можно создавать, редактировать, удалять.

**Agent Marketplace** — Магазин готовых агентов: загружаешь готовые профили (роль + промпт + модель).

---

## INFRASTRUCTURE (Инфраструктура)

**Providers** — API-ключи к LLM-провайдерам (Groq, Gemini, OpenRouter, NVIDIA и др.). Добавление, тестирование, статус, health-мониторинг.

**Key Pools** — Пулы ключей: группировка ключей по провайдерам, веса, приоритеты. Роутер выбирает из пула.

**Connectors** — Коннекторы к внешним системам (Slack, Telegram, Discord, email). Для отправки уведомлений и получения команд.

**MCP Servers** — Model Context Protocol серверы: внешние инструменты, к которым агенты могут обращаться (базы данных, API).

**Skills** — Навыки агентов: переиспользуемые модули (анализ кода, поиск, веб-скрапинг). Прикрепляются к агентам.

**Tools** — Инструменты: отдельные функции (калькулятор, выполнение кода в песочнице, парсинг, дата-анализ).

**Cache** — Управление кэшем LLM-ответов: статистика попаданий, ручная инвалидация по модели.

**Webhooks** — Вебхуки: внешние вызовы при событиях (дебат завершён, ключ истёк, ошибка провайдера).

**Rotations** — Ротация ключей: автоматическая смена ключей по расписанию или при достижении лимита.

**Key Groups** — Группы ключей для детального контроля: какие ключи к каким моделям привязаны, групповые лимиты.

## OBSERVABILITY (Наблюдаемость)

**Log Browser** — Все логи системы: фильтр по сервису, уровню (debug/info/warn/error), traceId. Поиск и анализ.

**Traces** — Трассировка запросов: полный путь запроса от UI до LLM-провайдера и обратно. Тайминги каждого этапа.

**Router Trace** — Трассировка решений роутера: какие провайдеры рассматривались, почему одни выбраны, другие отклонены.

**Memory** — Состояние памяти агентов: что помнят агенты между сессиями, семантическая память (схожие концепты).

**Health** — Здоровье провайдеров: latency, error rate, quota остаток, статус circuit breaker (открыт/закрыт).

**System Health** — Здоровье системы в целом: нагрузка на процессор, память, состояние сервисов.

**Docs Health** — Здоровье документации: какие .md файлы есть, битые ссылки, отсутствующие разделы.

**Pressure Map** — Карта давления: какие провайдеры под нагрузкой, уровень троттлинга, рекомендации.

**What-If** — Сценарии «что если»: симуляция отказа провайдера или ключа — как изменится маршрутизация?

**Runtime Pressure** — Давление рантайма: текущая нагрузка на очереди, треды, количество активных сессий.

**Provider Dashboard** — Панель всех провайдеров: сводка latency, успешность, стоимость, количество вызовов.

**Dependency Graph** — Граф зависимостей между сервисами: кто от кого зависит, DI контейнер, визуализация.

**Diagnostics** — Диагностика: проверка всех сервисов, их состояния, тестовые вызовы.

**State Inspector** — Инспектор состояния: просмотр полного состояния ядра (state.providers, state.weights, state.sessions).

**Profiler** — Профилировщик производительности: сколько времени занимает каждый этап обработки запроса.

**Shadow Compare** — Теневое сравнение: отправка запроса двум провайдерам одновременно, сравнение результатов без влияния на пользователя.

**Causal Debugger** — Причинно-следственный дебаггер: по цепочке событий определяет первопричину проблемы (почему упал latency, почему выбран этот провайдер).

**Counterfactual** — Контрфактический анализ: «а если бы у нас был ключ OpenAI, каким был бы ответ?».

**Session Bindings** — Привязки сессий: какие агенты к каким сессиям привязаны, состояние привязок.

## ECONOMICS (Экономика)

**Analytics** — Аналитика использования: графики запросов, токенов, стоимости по дням/неделям/месяцам.

**Routing AI** — Маршрутизация AI: настройка весов (скорость vs качество vs цена), профили маршрутизации (ECONOMY, BALANCED, PERFORMANCE).

**Economics** — Детальная экономика: стоимость каждого провайдера, модели, средняя цена за токен.

**Budget** — Бюджеты: лимиты на провайдера, предупреждения при превышении, автоматическая остановка при исчерпании бюджета.

**Cost Analytics** — Аналитика затрат: разбивка по провайдерам, моделям, агентам, дням. Прогноз на месяц.

**Provider Marketplace** — Рынок провайдеров: сравнение цен, скоростей, доступных моделей. Помогает выбрать лучшего провайдера под задачу.

---

## GOVERNANCE (Управление)

**Policies** — Политики: правила безопасности (какие темы запрещены, какие промпты блокировать), цензура, модерация.

**Roles** — Роли: RBAC (admin, user, viewer). Кто что может видеть и делать.

**Audit Log** — Журнал аудита: кто и когда что менял (ключи, политики, конфиги).

**Config History** — История конфигурации: все изменения конфига системы с временными метками, можно откатить.

**Service Registry** — Реестр сервисов: все 88+ сервисов системы, их статус, зависимости, события.

---

## KNOWLEDGE (Знания)

**Patterns** — Паттерны: повторяемые шаблоны взаимодействия агентов для типовых задач.

**Knowledge** — База знаний (семантическая): долговременная память агентов, факты, концепты, поиск по смыслу.

**Files** — Файлы: загруженные документы, изображения — агенты могут их анализировать.

**Documentation** — Встроенная документация системы (на русском и английском): описание всех сервисов, архитектуры, panels.

**Bookmarks** — Закладки: сохранённые сообщения, аргументы, дашборды для быстрого доступа.

**Message Search** — Поиск по всем сообщениям чата: полнотекстовый, с фильтром по агенту, дате, теме.

**Chat Export** — Экспорт чата: Markdown, JSON, текст. Выбор диапазона сообщений.

**Topics** — Генератор тем: AI предлагает темы для обсуждения на основе истории дебатов и интересов.

**Key Notes** — Быстрые заметки по ключам: комментарии, история, статус.

**Agent Journal** — Журнал агентов: каждый агент ведёт дневник своих действий и решений.

**Decision Log** — Журнал решений роутера: какие решения принимал роутер, почему, результат.

**Settings** — Настройки: тема (светлая/тёмная), язык (русский/английский), feature flags, about.

---

## RESEARCH (Исследования)

**Project OS Explorer** — Обозреватель проекта: файловая система проекта, поиск по файлам, просмотр кода.

**Hypothesis Generator** — Генератор гипотез: AI анализирует данные и предлагает гипотезы для исследования.

**Architecture Review** — Ревью архитектуры: анализ зависимостей, циклических ссылок, нарушений слоёв, Debt Report.

**Prompt & Strategy Audit** — Аудит промптов и стратегий: проверка всех промптов системы на качество, консистентность.

**Model Routing Experiments** — Эксперименты с маршрутизацией: A/B тестирование разных стратегий роутинга.

**Governance Stress-Test** — Стресс-тест управления: симуляция нарушений политик и проверка реакции.

**Observability Gaps Scanner** — Сканер пробелов наблюдаемости: какие метрики не собираются, какие события не логируются.

Строка состояния внизу экрана. Показывает live-статус системы в реальном времени: количество активных сессий дебатов, состояние circuit breaker'ов ключей, текущую нагрузку на роутер, последние события. Клик открывает мини-панель с деталями.
