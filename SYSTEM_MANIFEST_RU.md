# Super-Agents OS — СИСТЕМНЫЙ МАНИФЕСТ
**Версия**: 3.1.0
**Статус**: Промышленная контрольная панель (Стабильно)

## 🏗 Архитектурный манифест

### 1. Модель системы
Super-Agents OS — это детерминированная панель управления инференсом (LLM-ops), построенная вокруг централизованного **Системного Ядра (System Kernel)**. Система использует модель Event-Sourcing для управления переходами состояний и координации принятия решений в реальном времени. Каждая мутация состояния проходит через редуктор Ядра.

### 2. Ключевые слои архитектуры
1.  **Execution Layer (Слой исполнения)**: Потоковая передача, Racing Mode, цепочки Fallback и диспетчеризация запросов через `ChatService`.
2.  **Intelligence Layer (Слой интеллекта)**: Роутинг на базе Bandit-алгоритмов (UCB1) и оптимизация под SLA.
3.  **Stability Layer (Слой стабильности)**: Фиксация весов (Weight Anchoring) и прерыватели (Circuit Breakers).
4.  **Observability Layer (Слой мониторинга)**: Трассировка (requestId/traceId), метрики Four-Signals, региональный анализ и A/B эксперименты.
5.  **Predictive Layer (Слой прогнозирования)**: Прогноз исчерпания квот и советы Router Advisor.
6.  **Operator Layer (Слой управления)**: Интерфейс Dashboard v3.1 с Live Event Feed и заметками на базе SQLite Proxy.

### 3. Инварианты Системы
*   `INV-1`: Сумма весов роутинга (TTFT, TPS, Reliability) всегда равна 1.0.
*   `INV-2`: Ядро системы (Kernel) является единственным источником истины (SSOT).
*   `INV-3`: Любое решение роутера детерминировано состоянием Ядра и выбранной стратегией.
*   `INV-5`: Любое изменение режима SLA применяется ко всем узлам немедленно.

### 4. Технологический стек
*   **Core**: React 19 + TypeScript.
*   **State**: Event-driven Kernel + useKeyStore.
*   **Storage**: SQLite Proxy (DatabaseService) + LocalStorage.
*   **Visuals**: Framer Motion + Lucide Icons + Vanilla CSS (Glassmorphism).
